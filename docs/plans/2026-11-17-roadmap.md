# AgentOps Roadmap

Milestones are the build slices from `BRIEF.md`. Each milestone's detailed plan (`docs/plans/*-m<N>-*.md`) is written when that milestone starts. Its issues are listed here once the plan exists. Status lives on GitHub ([project board](https://github.com/users/edward-sf/projects/10)), not in this file.

| Milestone | Objective | Exit criteria | Plan |
| --------- | --------- | ------------- | ---- |
| [M0 - Architecture and project setup](https://github.com/edward-sf/AgentOps/milestone/1) | Application architecture, dev environment, data model, workflow tooling | App starts locally; connects to PostgreSQL; supports initial agent and dataset records | [M0 plan](2026-11-17-m0-architecture-setup.md) |
| [M1 - Agent execution and tracing](https://github.com/edward-sf/AgentOps/milestone/2) | Instrumented LangGraph agent producing structured traces | An agent completes a task; its execution can be reconstructed from stored trace and span records | [M1 plan](2026-11-19-m1-agent-execution-tracing.md) |
| [M2 - Evaluation engine](https://github.com/edward-sf/AgentOps/milestone/3) | Repeatable evaluation datasets against an agent | A dataset can be submitted and executed against an agent, storing a result per test case | Not yet written |
| [M3 - Scoring and evaluation analytics](https://github.com/edward-sf/AgentOps/milestone/4) | Accuracy, relevance, instruction adherence, tool correctness scoring | Every run produces a report with scores, failure explanations, and pass rate | Not yet written |
| [M4 - Dashboard and trace viewer](https://github.com/edward-sf/AgentOps/milestone/5) | Next.js UI for evaluations and traces | Launch an evaluation and drill down from aggregate results to a failed case and its trace | Not yet written |
| [M5 - Model comparison and regression detection](https://github.com/edward-sf/AgentOps/milestone/6) | Detect regressions between agent configurations | A deliberate change causes degradation; AgentOps identifies it and the failed cases | Not yet written |
| [M6 - Monitoring and cost analytics](https://github.com/edward-sf/AgentOps/milestone/7) | Latency, tokens, cost, and tool metrics | Compare two configurations on quality, latency, tokens, and cost | Not yet written |
| [M7 - Deployment and portfolio demonstration](https://github.com/edward-sf/AgentOps/milestone/8) | Deployed, reproducible demo on AWS | A reviewer can run the workflow, inspect traces, and reproduce the regression demo | Not yet written |
